\##Business requirements



\### 1. Business Content

Ecommerce company selling products through web and application channels



Operational systems for data -- customers, products, orders, payments, shipping, returns



Current case -- reporting directly on data sources which causes inconsistent data reporting, limited history analysis, performance issues





\### 2. Project Objective 

design and implement centralized data warehouse 



Warehouse objectives -- integrate data from multiple source systems, consistent data model, data marts for reporting



\### 3. Business Goals

1. Sales Performance
2. Customer behaviour
3. Order trends
4. Payment performance
5. Order trends
6. Shipping performance
7. Product returns 
8. Revenue trends



\### 4. Key Business Questions



The warehouse should allow analysts to answer questions such as:



1\. What is the total revenue by day, month and year?

2\. Which products generate the most revenue?

3\. Which product categories perform best?

4\. Which customers generate the most revenue?

5\. How many new customers are acquired each month?

6\. What percentage of customers are repeat customers?

7\. What is the average order value?

8\. Which products have the highest return rates?

9\. How long does it take to fulfill an order?

10\. What percentage of payments fail?

11\. Which geographical regions generate the most revenue?

12\. How has sales performance changed over time?





\### 7. Expected Outcome



The final solution will provide:



\- A centralized analytical warehouse

\- Historical data storage

\- Incremental data loading

\- Dimensional modeling

\- Data quality checks

\- Reconciliation

\- Analytical data marts

\- BI-ready datasets

\- Technical and architectural documentation
